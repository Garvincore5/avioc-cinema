# Our Family Hub for Android

This package uses the standalone, bundled Family Hub web app from `www/`. It runs offline and stores its data in the app's local browser storage on this device. The current source has cross-tab synchronization, but it has no hosted family account or cloud sync service; data entered on one phone will not appear on another phone automatically.

The signed release APK is built in GitHub Actions with the Avioc Android signing key. Android package ID: `com.avioc.familyhub`.

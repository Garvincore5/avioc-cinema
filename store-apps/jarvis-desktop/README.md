# J.A.R.V.I.S. Desktop Companion

This Windows desktop edition packages the separate .NET 10 HUD project from `E:\code\ai-companion`. It serves its bundled interface from a localhost-only HTTP server and opens it in Microsoft Edge's app window, with a browser fallback.

The companion's Gemini features need the user to enter their own API key in the app. The key is kept in that user's browser storage. The application is not code-signed for Windows.

The Avioc AI Companion product remains the cross-platform edition. This package preserves the separate J.A.R.V.I.S. HUD design and is currently Windows x64 only.
